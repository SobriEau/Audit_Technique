# Prompts de régénération

Ce dossier contient les consignes à donner à un assistant IA pour refaire un
travail déjà fait une fois, sans repartir de zéro ni retomber dans les pièges
déjà rencontrés.

| Prompt | Quand l'utiliser |
|---|---|
| [regenerer-audit-technique.md](regenerer-audit-technique.md) | Une nouvelle version de `audit_technique.xlsx` arrive et la partie technique doit être remise à jour. |

Ces fichiers ne sont pas de la documentation du projet — celle-ci vit dans
[CLAUDE.md](../CLAUDE.md) et [docs/](../docs/). Ce sont des **modes opératoires
adressés à une IA**, écrits après coup, à partir de ce qui s'est réellement
passé la première fois.
