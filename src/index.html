SobriEau n'a pas pu démarrer

Ce poste empêche l'application de s'exécuter. Trois causes fréquentes :

  1. Le fichier est bloqué par Windows. Clic droit sur index.html → Propriétés → cocher Débloquer en bas → Appliquer, puis rouvrir.
  2. Le navigateur est trop ancien. Ouvrir avec une version récente de Chrome ou Edge.
  3. Une stratégie d'entreprise interdit les pages locales ou les scripts. Il faut alors passer par la version hébergée.

Pour le support, appuyez sur F12 puis onglet Console, et transmettez ce qui s'y affiche avec la ligne suivante :

Navigateur : (script non exécuté — c'est déjà une information)
